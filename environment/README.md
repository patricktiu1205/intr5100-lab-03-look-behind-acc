# Supplied Lab III Environment

These files are unmodified copies of the course setup. Their SHA-256 hashes are recorded in `review/supporting_file_manifest.json` at the repository root. Do not edit the map, GUI, experiment runner, IDM or I/O implementation.

`student_controller3.py` in this folder is the original commissioning template. The repository-root file with that name is the developed submission. Tests copy the supplied environment into a temporary directory and replace only the controller there; they do not connect to physical vehicles.
